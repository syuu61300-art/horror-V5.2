# 闇の一軒家 ― 脱出

ブラウザで遊べる一人称3Dホラー脱出ゲーム（Three.js）。

## 遊び方
懐中電灯と電池を探し、家中（母屋11部屋＋離れ5部屋）に隠された12個の鍵（位置は毎回ランダム）を集めて、幽霊から逃げながら玄関から脱出します。幽霊は歩きより速いので、ダッシュ・しゃがみ・物陰を使い分けて逃げましょう。

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 視点 | マウス |
| ダッシュ | Shift を押しながら移動 |
| しゃがみ | C（押している間）／ 廊下の板戸の前で押すと…？ |
| スライディング | 移動中に Shift + C |
| 調べる | F（ベッドの上の日記に照準を合わせて） |
| 隠れる／出る | Q（ベッド・クローゼット・箱などに照準を合わせて） |
| 鍵を使う | G（鍵を12個集めて玄関の扉の前で） |
| ライト | E（懐中電灯を拾うと使用可） |
| メニュー・設定 | Esc |

設定（感度・FOV・モーションブラー・明るさ・音量・描画解像度・FPS上限・FPS表示）はタイトル画面、または Esc のメニューから変更できます。

## 横画面
縦持ちのときは自動で画面を90度回転して横画面表示にします（設定「縦持ち時は横表示」でオフ可）。端末を横向きにすると通常表示になります。

## 敵AI
幽霊は1体（追跡1.58m/s・巡回0.73m/s）。足音（走る・滑る・歩く）やアイテムを拾う音、ライトの切り替え音などの物音に反応して、その場所を調べに来ます（壁越しだと聞こえる距離は短くなります）。ゲーム開始時はプレイヤーから最も遠い場所（玄関など）に出現し、ドアなどで詰まって動けなくなったときもプレイヤーから最も遠い場所へ再スポーンします。

## 離れ（和風の別棟）
母屋の廊下の東の突き当たりから「渡り廊下」でつながる別棟です。茶室・仏間・大座敷・蔵・書院の5部屋があり、鍵（毎回3〜4個）・電池3つが隠されています。
廊下の途中は床が抜けていて、立てかけられた板戸が道をふさいでいます。**板戸の近くで「しゃがむ」を押すと板が倒れて橋になります**（大きな音が響くので、近くに幽霊がいると寄ってきます）。一度倒すと、幽霊も離れに入れるようになります。
壁紙は青海波・襖（金箔と水墨）・黒漆と金格子・海鼠壁・麻の葉・障子と土壁の6種を新規に用意しました。

## 鍵のランダム配置
鍵は12個。`game.js` の `KP`（各部屋の机・棚・床の隅など約60か所の候補地点）から、ゲーム開始・リトライのたびにランダムに選びます。
ルール: 1部屋に1個まで／鍵どうしは3.2m以上離す（無理なら段階的に緩和）／スタート位置と幽霊の初期位置の近くは避ける／離れに3〜4個。
幽霊の速度は `GS`、初期位置は `GSTART`、積極度は `GBIAS` で調整できます。

## ガイドとクリア演出
懐中電灯を拾うまでは、画面上の矢印・距離表示・光の柱で場所が分かります。拾った後は案内なしで、鍵は自力で探します。
全部の鍵で玄関を開けると、扉が開き、夜明けの中へ出て白くフェードする演出のあと結果画面（タイムで★評価）が出ます。

## 隠れる・日記
ベッド・クローゼット・押し入れ・木箱・長持に照準（画面中央の点）を合わせて Q（スマホは右側に出る「隠れる」ボタン）で隠れられます。隠れ場所ごとに視野が変わります（ベッドの下は床すれすれの横長、クローゼットは扉のすき間、箱は縁から覗く形）。見られていない状態で隠れれば幽霊は見失いますが、近くに長くいると見つかります。見られているときも隠れられますが、幽霊は探すふりをしてから捕まえに来ます。
2つのベッドの上に日記が置かれていて、F で読めます。読んでいる間は幽霊がその場に留まります。

## スタミナ・隠れる・日記の操作
スタミナの最大値は通常の1.5倍です。隠れている間は画面の鮮明度が約75%になり、2割ほど霞がかかります（暗くなりすぎないよう明るさを補正）。
日記を読んでいる間はプレイヤーは動けず、幽霊もその場に留まります。日記を閉じる／隠れ場所から出るには、画面をタップ（クリック）するだけでOKです（ボタン上のタップは除く）。

## 演出（PC・スマホ共通。スキップ不可・最後まで強制再生）
- **開始**: ベッドで目を覚ますと、幽霊らしき人影が1秒だけ目の前に現れ、「…なんだ、あいつは…」と言って消える。テロップ「まずは懐中電灯を探そう。」。
- **死亡**: 幽霊が飛びかかって顔いっぱいに迫り、大きな口が上下からガブッと閉じて暗転（食われる演出）。
- **クリア（約22秒）**: 鍵が回って扉が開く → 主人公が外へ出る → 戸口に幽霊が佇む（テロップ「早くどこかに逃げなきゃ…」）→ 走って逃げ切る → 夜明け → 「脱出成功」→ 白くフェードして結果画面。
  玄関の壁は開口部にして、ドアの部分はドアだけにしてあります。外には地形・庭・石畳・門・道路・木・月・星・街灯・ポーチの灯りがあります。

## その他の仕様
- 懐中電灯を拾うまでは、バッテリーゲージと「ライト」ボタンを表示しません。場所は大きな矢印（距離つき）と光の柱で分かります。
- 設定の「FPS上限」に 240 / 360 / 500 を追加（144以上は垂直同期に縛られない高FPSループ）。FPS表示は0.5秒ごとに更新、最大500まで表示します。
- 起動時に全テクスチャ・シェーダー・ジオメトリを先にGPUへ読み込み、視点を動かしたときの初回描画によるカクつきを減らしています。

## スマホ操作
左スティック＝移動 ／ 右側ドラッグ＝視点 ／ 右下の丸ボタン＝ダッシュ（切替）・しゃがむ（切替）・スライド・ライト ／ 中央の点（照準）を物に合わせると、右側に大きな「読む」「隠れる」「鍵を使う」ボタンが出るのでタップ ／ 右上☰＝メニュー・設定。
スマホを自動判定します（設定の「タッチ操作」で手動切替も可）。横画面推奨。

## 更新内容（v3）
- **隠れる**を `H` → `Q` キーに変更。
- **演出は全てスキップ不可**（導入・クリア）。
- **幽霊の索敵**: 壁越しには見つけません。視界（壁なし＋前方約60°の視野）に入ったときだけ追跡し、見失うと最後に見た場所へ向かいます。足音も壁越しでは届きません。パトロール中にプレイヤーの現在地へ向かう補正も廃止。
- **死亡後の二重表示を修正**: 「もう一度」後、裏で死亡演出が再生されて結果画面が再表示される問題を修正（リセット中は演出を止める）。
- **クリア演出**: 玄関の左右・上・東面・離れの外壁を追加して中が見えないように。主人公は庭門を抜けて角を曲がり、**公道を走って逃げる**。夜明けのあとにエピローグ（約44秒）。
- **主人公モデル**を作り直し（手足の関節・髪・顔・フード付き上着・靴・懐中電灯）。
- **画質「最高」**を追加（MSAA最大8x・影4096・ブルーム強化・シャープ化）。「高」もシャープ化。
- **ストーリー導入**: 起動後の初回は、安い家賃の理由→前の住人→日記→最後のページ…という夢をテロップで流し、物音で目が覚める。リトライ時は短縮版（物音で目覚め→人影）。
- **死亡演出**: 悲鳴・フラッシュ・「みーつけた」→ガブッ→画面に返り血と血のしたたり。

## 更新内容（v4）
- **文字化け・文字の重なり**を修正（導入テロップのレイアウト崩れ、メッセージ/テロップ/隠れ中ヒントの重なり）。
- **読み上げ**（設定で ON/OFF・声の音量）: ブラウザの音声合成(日本語)で、テロップ・日記・独白を主人公が読み上げ。幽霊の「みーつけた」は高い声。文字は**タイプ音付きで1文字ずつ**表示し、読み上げの終了に合わせて次へ進みます。
- **主人公の声**: 独白に加え、息づかい・息切れ・驚き・悲鳴・うめきを合成（合成音声）。
- **効果音を59種**に拡充（足音(板/畳/しゃがみ/ダッシュ/幽霊)・スライド・布ずれ・拾う(鍵/電池/ライト)・ライトON/OFF/点滅/電池切れ・日記(紙/ページ)・タイプ(通常/スペース/改行)・隠れる(出入り/押し入れ/ベッド下/息を止める)・鍵/扉/板の崩落・ノック・家鳴り・水滴・風・時計・ささやき・幽霊の叫び/飛びかかり/噛みつき・血しぶき/滴り・環境音(虫/車/鳥/チャイム)ほか）。ステレオ定位＋距離減衰つき。
- **隠れる判定を修正**: 見られていない状態で隠れた場合は、幽霊が近くにいても見つかりません（長居した幽霊は立ち去ります）。見られていた場合のみ追ってきます。
- **見つかった時の演出**: 隠れ場所がこじ開けられ、幽霊の顔と手が迫り「みーつけた」→噛みつき。
- **日記**: 開くとカメラが日記を背景に少し傾き、軽くぼけた画面で、日記の文章がテロップ（タイプ音＋読み上げ）で流れます。
- **血の表現**を作り直し（濃い赤〜暗赤、ツヤ、飛沫、引きずり跡、したたり）。
- **主人公モデル**を関節つきリグで作り直し（顔・髪・フード・手指・靴・リュック・懐中電灯）。歩き／走り／**後退り**／待機のアニメーションを追加（歩幅と移動速度を連動、膝・足首・腰の上下動・体幹のひねり・腕振り）。
- **クリア演出の外壁**を、下見板張りの外装に修正（室内の壁紙が外から見えていたため、壁の向こうが見えているように見えていました）。
